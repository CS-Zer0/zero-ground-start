# Zero Ground Blog

This repository contains a minimal Next.js project for a simple blog.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the blog.

The homepage lists posts from `posts.js` and clicking on a title opens the post page.
